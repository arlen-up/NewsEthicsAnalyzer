# 📰 뉴스 편향 헤드라인 감독기 (News Bias Headline Analyzer)

> **"우리가 읽는 뉴스는 얼마나 공정할까요?"** > AI를 통해 뉴스 헤드라인의 편향성을 실시간으로 감지하고 감독하는 Streamlit 웹 애플리케이션입니다.

🚀 **실시간 서비스 확인하기:** [👉 넷앱 링크 이동](https://newsethicsanalyzer.streamlit.app/)

---

## ✨ 주요 기능 (Key Features)

* **🔍 헤드라인 편향성 분석:** 입력한 뉴스 헤드라인의 톤앤매너와 단어 선택을 분석하여 편향성 여부를 판단합니다.
* **📊 시각화 대시보드:** 분석 결과를 점수나 그래프 등 직관적인 UI로 제공합니다. (Streamlit 기반)
* **💡 대안 제시 (선택 사항):** 편향된 헤드라인을 보다 중립적이고 객관적인 헤드라인으로 교정하여 제안합니다.
